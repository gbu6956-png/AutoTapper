# 자동 탭 (AutoTapper)

화면에 타겟 이미지(기본: 첨부한 갈색 동물 얼굴)가 보이면, 여러 개여도 전부 즉시 탭하는 안드로이드 앱입니다.

## 동작 방식
1. **화면 캡처**: MediaProjection으로 화면을 1/3 해상도로 계속 받아옵니다 (화면 주사율만큼, 보통 60~120fps).
2. **이미지 인식**: OpenCV 템플릿 매칭으로 한 프레임 안의 타겟을 모두 찾습니다 (축소 + 흑백이라 수 ms).
3. **탭**: 접근성 서비스의 `dispatchGesture`로 찾은 위치를 한 번에(멀티터치) 탭합니다.

처음 타겟이 화면에 보이면 아이콘 크기를 자동으로 찾아서 고정합니다.

## APK 만들기 (둘 중 하나)

### A. GitHub에서 자동 빌드 (PC에 아무것도 설치 안 해도 됨)
1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다 (`.github` 폴더 포함).
2. 저장소의 **Actions** 탭 → `Build APK` 실행이 끝나면 (약 5분) → **Artifacts**의 `AutoTapper-apk` 다운로드.
3. 압축을 풀면 나오는 `app-debug.apk`를 폰에 옮겨 설치합니다.

### B. Android Studio
1. Android Studio에서 이 폴더 열기 → Gradle 동기화 기다리기.
2. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. `app/build/outputs/apk/debug/app-debug.apk` 설치 (또는 폰을 USB로 연결하고 ▶ 실행).

## 폰에서 사용하기
1. APK 설치 ("출처를 알 수 없는 앱" 허용 필요).
2. 앱 실행 → **1. 접근성 권한 켜기** → 설치된 앱 → 자동 탭 → 켜기.
   - **"제한된 설정"이라며 안 켜지면** (Android 13 이상, 직접 설치한 앱):
     설정 → 애플리케이션 → 자동 탭 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도.
3. **2. 시작** → 화면 공유 창에서 **전체 화면** 선택 → 게임 화면으로 이동.
4. 끄려면 알림창의 **중지** 버튼.

## 설정
| 항목 | 설명 |
|---|---|
| 일치도 기준 % | 기본 80. 엉뚱한 곳을 누르면 올리고, 못 찾으면 내리세요. |
| 같은 자리 재탭 대기 ms | 같은 아이콘을 연타하지 않도록 기다리는 시간. 0이면 매 프레임마다 누름. |
| 캡처 축소 배율 | 기본 3. 4~5로 올리면 더 빠르지만 아주 작은 아이콘은 못 찾을 수 있음. |
| 탭 누름 시간 ms | 기본 5. 게임이 탭을 무시하면 30~50으로 올려보세요. |
| 색상까지 비교 | 모양은 같고 색만 다른 가짜(폭탄 등)가 있으면 켜세요. 조금 느려짐. |
| 여러 개 동시에 탭 | 끄면 멀티터치 대신 아주 짧은 간격으로 하나씩 누름. |

타겟 이미지는 **타겟 이미지 바꾸기**로 다른 이미지(화면 캡처를 잘라낸 것)로 바꿀 수 있습니다.
배경이 들어가지 않게 아이콘 안쪽만 잘라서 쓰면 가장 정확합니다.

## 속도에 대해
화면 표시 → 캡처 → 인식 → 탭까지 실제 지연은 폰에 따라 대략 **20~50ms** 입니다.
화면 자체가 60Hz면 8~16ms마다 한 번씩 바뀌기 때문에, 정확히 0.01초(10ms)는 어떤 앱으로도 보장할 수 없습니다.
앱 안의 상태 표시에서 실제 fps와 인식 시간(ms)을 확인할 수 있습니다.
